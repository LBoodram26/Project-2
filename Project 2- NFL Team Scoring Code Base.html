Clean the NFL Team Scoring Data

After examining the NFL scoring table, I found that it contains 32 teams and five columns. The dataset includes rushing touchdowns, receiving touchdowns, total touchdowns, and two-point conversions.

I also noticed that the team names were duplicated during the import process. For example, the Buffalo Bills appeared as BillsBills. I will correct the team names, rename the scoring columns, and check for missing values and duplicate records.

I will also calculate the number of touchdowns that are not classified as rushing or receiving by subtracting those categories from the total touchdowns.

# Rename the original NFL columns
nfl_clean <- nfl_raw |>
  dplyr::rename(
    team = Team,
    rushing_td = `Rsh TD`,
    receiving_td = `Rec TD`,
    total_td = `Tot TD`,
    two_point = `2-PT`
  )

# Correct duplicated team names
nfl_clean <- nfl_clean |>
  dplyr::mutate(
    team = stringr::str_replace(
      team,
      "^(.+?)\\1$",
      "\\1"
    )
  )

# Calculate touchdowns classified as other
nfl_clean <- nfl_clean |>
  dplyr::mutate(
    other_td = total_td - rushing_td - receiving_td
  )

Transform NFL Scoring Data From Wide to Long Format

After cleaning the NFL scoring dataset, I confirmed that it contains 32 teams with no missing values or duplicate records. I also corrected the team names and calculated the number of touchdowns that were not classified as rushing or receiving.

I will now use pivot_longer() from the tidyr package to reorganize the touchdown categories into a tidy format. Instead of having separate columns for rushing, receiving, and other touchdowns, I will create a touchdown type column and a touchdown count column.

I will preserve the original total touchdowns and two-point conversion measurements so I can use them for additional comparisons and data validation.

# Transform the NFL scoring categories into tidy format
nfl_tidy <- nfl_clean |>
  tidyr::pivot_longer(
    cols = c(
      rushing_td,
      receiving_td,
      other_td
    ),
    names_to = "touchdown_type",
    values_to = "touchdowns"
  ) |>
  dplyr::mutate(
    touchdown_type = dplyr::recode(
      touchdown_type,
      rushing_td = "Rushing",
      receiving_td = "Receiving",
      other_td = "Other"
    )
  ) |>
  dplyr::arrange(team, touchdown_type)

Calculate Touchdown Percentages by Team

After transforming the NFL scoring dataset into a tidy format, I now have 96 observations representing 32 NFL teams and three touchdown categories.

The validation results confirmed that the rushing, receiving, and other touchdowns add up to the reported total touchdowns for all 32 teams.

I will now calculate the percentage of touchdowns scored in each category to compare the different scoring styles of NFL teams. This will help identify which teams rely more on rushing touchdowns and which teams rely more on receiving touchdowns.

I will also check whether any teams have unusually high percentages of touchdowns classified as other.

# Calculate the percentage of touchdowns by category
nfl_percentages <- nfl_tidy |>
  dplyr::mutate(
    touchdown_percentage = dplyr::if_else(
      total_td > 0,
      round((touchdowns / total_td) * 100, 2),
      NA_real_
    )
  ) |>
  dplyr::arrange(team, touchdown_type)

Visualize NFL Team Scoring Styles

After calculating touchdown percentages, I found that NFL teams have different scoring patterns. The Colts and Falcons had the highest percentage of rushing touchdowns at approximately 72.7%, while the Raiders had the highest receiving touchdown percentage at approximately 85.7%.

I also identified several teams with touchdowns classified as other, which were calculated by subtracting rushing and receiving touchdowns from the reported total.

I will use ggplot2 to create a stacked bar chart showing the percentage of rushing, receiving, and other touchdowns for all 32 NFL teams. This will make it easier to compare scoring styles and identify differences between teams.

# Set the order of touchdown categories
nfl_plot_data <- nfl_percentages |>
  dplyr::mutate(
    touchdown_type = factor(
      touchdown_type,
      levels = c("Rushing", "Receiving", "Other")
    )
  )

# Create a stacked bar chart
ggplot2::ggplot(
  nfl_plot_data,
  ggplot2::aes(
    x = team,
    y = touchdown_percentage,
    fill = touchdown_type
  )
) +
  ggplot2::geom_col() +
  ggplot2::coord_flip() +
  ggplot2::labs(
    title = "NFL Team Touchdown Scoring Styles",
    subtitle = "2026 Regular Season – Data Collected October 11, 2026",
    x = "NFL Team",
    y = "Percentage of Total Touchdowns (%)",
    fill = "Touchdown Type"
  ) +
  ggplot2::theme_minimal() +
  ggplot2::theme(
    axis.text.y = ggplot2::element_text(size = 8),
    legend.position = "bottom"
  )

Summary of Findings

In my analysis of my third dataset, I utilized NFL team scoring statistics for the 2026 regular season. The dataset comprised 32 teams and featured columns for rushing touchdowns, receiving touchdowns, and other touchdowns.

I began by scrubbing the data by amending duplicate team names and ensuring no missing data. I then applied the pivot_longer() function to collate rushing and receiving touchdowns into one tidy piece of data. As a result, this step increased the number of observations substantially from 32 to 96 observations.

After the computation of touchdown ratios, the results indicated that the Colts and Falcons had the highest rushing touchdown ratios of 72.7%. The team that had the highest receiving touchdown ratio was the Raiders with an approximate percentage of 85.7%.

I also established that there were several teams that each had one touchdown labeled as the other. These other touchdowns resulted from subtracting the rushing-touchdowns from the total touchdowns.

While analyzing total touchdowns, the Cowboys, Bills, and the 49ers were all tied with 16 touchdowns each.

In any case, this project was crucial in understanding how tidy data improves data comparison of different scoring types. With the help of tidyr, dplyr, and ggplot2, I succeeded in restructuring data, calculating percentages, verifying sums, and producing appropriate charts that facilitated the perception of differences among teams.

In light of the fact that the NFL season is running, this data is relevant as of October 11, 2026, rather than the data for the end of the season.
